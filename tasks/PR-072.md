## Problem

Continuation of PR-071, but for the web layer and the application bootstrap. PR-071 covers parsers, services, and DB layer; this PR covers `web/*`, `app.py`, `__main__.py`, and any remaining gaps in the package init.

The web layer is **the highest-risk perimeter for coverage gaps**: `routes.py` alone has 196 uncovered statements, mostly error/exception branches in mutating endpoints. Each uncovered branch is a code path that has never been exercised, and the audit found this layer carries security-critical logic (CSRF cookie parsing, rate-limit slot release, drive-replace state-machine errors). Coverage at 100% is mandatory and `# pragma: no cover` is forbidden.

## Strategy

Same as PR-071: enumerate gaps with `--cov-branch --cov-report=term-missing`, categorize, write tests.

The dominant categories for the web layer are:
1. **Storcli error paths in routes** (~80 statements). Each mutating endpoint has a `try/except StorcliError` that is rarely exercised. Cover by configuring the test fixture's storcli runner to raise on demand.
2. **CSRF cookie edge cases** (~12 statements). Malformed Cookie header, missing morsel, exception during cookie parse. Cover with crafted `Cookie` headers.
3. **Rate-limit slot release** (~21 statements). Cancellation while slot reserved; non-401 status causing slot release; eviction race. Cover with `asyncio.Task.cancel()` and `monkeypatch` on the auth middleware.
4. **App lifespan retry loop** (~32 statements). Collector lock contention; lock release on exception; retry success; retry permanent failure. Cover with `tmp_path` lock files and forced contention.
5. **`__main__.py` entry point**. Cover via `runpy.run_module("megaraid_dashboard", run_name="__main__")` with `uvicorn.run` mocked.
6. **Metrics endpoint edge cases** (~1 statement). Cover by inducing the missing branch.

## Implementation notes (READ BEFORE CODING)

`# pragma: no cover` is forbidden. Same rules as PR-071.

The `__main__.py` entry point uses `uvicorn.run(create_app(), ...)`. Testing approach:

```python
import runpy
from unittest.mock import patch

def test_main_runs(monkeypatch):
    monkeypatch.setattr("uvicorn.run", lambda *a, **kw: None)
    runpy.run_module("megaraid_dashboard", run_name="__main__")
```

The `runpy.run_module` invocation re-executes `__main__.py` as `__main__`. The `if __name__ == "__main__": main()` line fires; `main()` calls `uvicorn.run`, which is mocked. Both the function definition line AND the `__name__ == "__main__"` branch get covered.

The `CancelledError` path in `_start_collector_scheduler` is reachable by cancelling the lifespan task during startup. Use `asyncio.create_task` plus `task.cancel()`.

For rate_limit.py slot release on cancellation: spawn a task that hits a protected endpoint, cancel mid-request via `task.cancel()`, then assert `_attempts[client_ip]` does not contain the cancelled slot.

For routes.py error paths: most follow the pattern

```python

    result = await asyncio.to_thread(runner.run, argv)
except StorcliError as exc:
```
