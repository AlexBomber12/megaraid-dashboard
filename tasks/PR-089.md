## Implementation notes

Screenshots should be taken from a real deployed instance at 1920x1080 viewport. Use a tool like Playwright headless or Firefox/Chrome screenshot mode. Mask any sensitive data (serial numbers can be left visible; they're not secrets).

Documentation should be honest about limitations:
- HTMX polling is 30s lag, not real-time.
- Backplane diagram slot order may not match physical layout until per-deployment mapping is configured.
- Buzzer sounding detection is not possible from snapshot (silence acts on current state, not on detection of sounding).

The CHANGELOG entry should be operator-facing, not developer-facing. Example structure:

```markdown
## [Unreleased] - Dashboard redesign

### Added
- New main page layout: 1 controller tile + 8-drive grid + activity timeline.
- Controller detail page (/controller) with RoC temperature history graph.
- Drive detail page redesign with backplane position diagram and inline error sparkline.
- Buzzer control: Silence / Disable / Enable physical alarm from web UI.
- Advanced drive actions: Mark UBad/UGood, Spin Down, Make Hot Spare.
- Auto-refresh every 30 seconds (no manual reload needed).

### Fixed
- Drive detail temperature/error charts no longer grow uncontrollably (now fixed 220px height).
- Activity feed shows 10 latest events with relative age ("3 days ago").
- Controller alarm tile no longer red when buzzer config is "On" (configuration ≠ active alarm).

### Removed
- Legacy strip-of-tiles overview layout.
- Legacy partial endpoints replaced by /partials/main-page.
```
