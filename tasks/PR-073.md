## Problem

PR-071 brought services/, storcli/, db/ to 100% line and branch coverage. PR-072 was subdivided into 8 sequential sub-PRs (PR-072a through PR-072h) that brought the web/ layer plus app.py and __main__.py to 100%. Without a CI gate, the next PR can regress without anyone noticing. This PR is the lock: it enables `--cov-fail-under=100`, `--cov-branch`, and `--cov-report=term-missing` as default pytest options. It also extends ruff lint config to flag bare `# type: ignore` (no error code).

The work in this PR is minimal: <10 lines across 3 files. There are no test changes (those happened in PR-071 and PR-072a..h) and no production code changes.

## Implementation notes

The `--cov-fail-under=100` flag makes pytest exit non-zero if total coverage drops below 100%. The number applies to the combined line+branch percentage when `--cov-branch` is also enabled. Verify behavior locally first:

```
python -m pytest
```

Expect: 100% in the terminal report, exit code 0. If anything is below 100%, exit code non-zero with a message naming the offending file and percentage.

Adding `PGH` to ruff `select` enables three rules:
- `PGH003`: forbids bare `# type: ignore` (must specify error code like `# type: ignore[arg-type]`).
- `PGH004`: forbids bare `# noqa` (must specify rule code like `# noqa: N818`).
- `PGH005`: enforces correct method names on `unittest.mock` (rare; mostly applies to test code).

The three existing `# type: ignore` annotations in production code already use the bracketed-error-code form (verified during the L1 audit). Any `# noqa` in `storcli/exceptions.py` (N818 for custom exception naming) should also be bracketed.

If ruff flags any annotation as bare during the gate run, fix the annotation in this same PR with the explicit code. Do NOT remove the annotation entirely; understand why it was added and add the correct code.

If a future PR introduces a bare `# type: ignore`, ruff will flag it before merge, preserving the discipline established here.

## Verification

```
python -m pytest
python -m ruff check .
```

Both must pass: pytest with 100% TOTAL coverage and ruff with PGH active.

Deliberate regression check (do NOT commit, just verify the gate fires):

```
# In a fresh branch, introduce an unreachable line
echo "def _never_called(): return 42" >> src/megaraid_dashboard/__init__.py
python -m pytest
# Expect: FAIL with coverage below 100% and the offending file named.
git checkout -- src/megaraid_dashboard/__init__.py
```

This dry-run confirms the gate is wired correctly. Then verify ruff:

```
# In a fresh branch, add a bare type: ignore
echo "x = 1  # type: ignore" >> tests/test_versioning.py
python -m ruff check .
# Expect: PGH003 violation reported.
git checkout -- tests/test_versioning.py
```
