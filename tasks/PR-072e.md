## Implementation notes

The patrol-read endpoints are similar in shape: each has request validation, storcli call, audit emission, response. Cover each error path:
1. Storcli runner returns error (mock raises StorcliError or StorcliCommandFailed).
2. Audit insert fails (mock session.execute raises SQLAlchemyError).
3. Body validation fails (malformed JSON, wrong types, out-of-range values).
4. State-machine violation (trying to stop when not running, start when already running).

The mode endpoint accepts three values; parametrize across them and across the bad-input cases.
