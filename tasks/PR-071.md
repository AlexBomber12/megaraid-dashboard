## Problem

The project requires 100% line + branch coverage on production code. Current state on main is **89% line coverage**, no branch coverage gate. The gap is concentrated in three layers: parsers (`storcli/`), services (`services/`), and the DB DAO layer (`db/`). This PR closes the gap for those layers. Web layer and `app.py` are covered by PR-072. The coverage gate itself is enabled in PR-073.

The 100% requirement is non-negotiable. **The use of `# pragma: no cover` is forbidden in this PR.** Defensive `raise RuntimeError(...)` branches (e.g. `if len(token) != expected: raise`) must be exercised through monkey-patched dependencies, not annotated away. CLI entry points must be exercised via `runpy.run_module(...)`. Unreachable type-narrowing branches must be exercised by passing mistyped inputs to the parsers.

## Strategy

Run pytest with branch coverage to enumerate the gap precisely:

```
python -m pytest --cov=src/megaraid_dashboard --cov-branch --cov-report=term-missing -q
```

Categorize the missed lines/branches before writing tests. The categories observed in the audit:

1. **Defensive type-narrowing** (parsers receiving non-string values from storcli). Cover by passing dict / int / float / object to the parser helpers and asserting `TypeError` with the exact message.
2. **Error / exception paths** in services. Cover by `monkeypatch.setattr` on the dependency that raises (`session.execute = Mock(side_effect=SQLAlchemyError)`, etc.) and asserting the documented response.
3. **Lock file edge cases** (scheduler's `_try_acquire_notifier_lock`). Cover with `tmp_path` fixtures plus `os.symlink` for ELOOP, `os.link` for hard-link, `os.fchown` for ownership mismatch, `fcntl.flock` mock for `BlockingIOError`.
4. **Retry / cancellation paths** (asyncio). Cover with `pytest.raises(asyncio.CancelledError)` and `asyncio.Task.cancel()` orchestration.
5. **`__init__.py PackageNotFoundError`**. Cover by:
   ```
   monkeypatch.setattr(importlib.metadata, "version", _raises(PackageNotFoundError))
   importlib.reload(megaraid_dashboard)
   assert megaraid_dashboard.__version__ == "0.0.0+unknown"
   importlib.reload(megaraid_dashboard)  # restore
   ```

## Implementation notes

`# pragma: no cover` is forbidden. If a test cannot be written for a line or branch:
1. First try harder: monkey-patch the right dependency, use `runpy.run_module`, use `importlib.reload`.
2. If technically impossible, the production code is wrong: it has unreachable code that should be removed.
3. Only as a last resort, document the obstacle in the PR description and reach out for review. Do not commit the bypass.

The `unreachable defensive RuntimeError` pattern (e.g. `csrf._generate_token`'s length check) is reachable via `monkeypatch.setattr(secrets, "token_bytes", lambda n: b"\x00" * 1)`. The `secrets.token_bytes` function is replaceable; the RuntimeError fires on the unexpected length. Use the same approach for similar constructs.

The `__init__.py PackageNotFoundError` branch is reachable. Pattern:

```python
import importlib
import importlib.metadata
import megaraid_dashboard

def test_version_fallback_when_package_missing(monkeypatch):
    def _raise(name):
        raise importlib.metadata.PackageNotFoundError(name)
    monkeypatch.setattr(importlib.metadata, "version", _raise)
    importlib.reload(megaraid_dashboard)
    try:
        assert megaraid_dashboard.__version__ == "0.0.0+unknown"
    finally:
        # Restore real version. monkeypatch.setattr is auto-undone after
        # the test, but the reload above already cached the fallback.
        importlib.reload(megaraid_dashboard)
```

The `alerts/__init__.py` lines 18-20 are likely a similar metadata fallback. Apply the same pattern.

For storcli `_parse_*` helpers in `models.py`, the `not isinstance(value, str)` guards are reachable by passing raw `dict`, `bytes`, `bool`, or custom objects. Add a parametrize block per helper:

```python
@pytest.mark.parametrize("value", [{}, [], object(), b"42", True])
def test_parse_temperature_rejects_non_string(value):
    with pytest.raises(TypeError, match="expected temperature string"):
        _parse_temperature(value)
```

For scheduler's `_try_acquire_notifier_lock`:
- ELOOP via `os.symlink(target, lock_path)` where target does not exist.
- BlockingIOError via patching `fcntl.flock` with `Mock(side_effect=BlockingIOError)`.
- Hardlink rejection via `os.link(other_file, lock_path)` then attempting to acquire.
- Ownership mismatch via `os.chown(lock_path, other_uid, -1)` if running with sufficient privilege; otherwise via `monkeypatch.setattr(os, "fstat", ...)` returning a stat result with foreign uid.

For the retry path in `app.py:_retry_collector_scheduler_start` (note: this file is in PR-072's scope, NOT this PR), no work here.

Branch coverage for `if a and b` style conditions requires testing both `(a=False)` and `(a=True, b=False)` and `(a=True, b=True)`. Use parametrize. The `--cov-branch` flag will surface the missed branch automatically.

For `try/except`, both the success path and the exception path must execute. Use `monkeypatch.setattr` on the inner call.

For `for x in items: ... else: ...` (Python's `for/else`), the else branch is hit only when the loop completes without `break`. Both paths must be exercised separately.

If a parser helper is dead code (no caller), it should be removed in this PR with justification. Coverage tools cannot exercise dead code, so the only way to reach 100% is to delete it.
