## Implementation notes

For CSRF token length test: `secrets.token_bytes(n)` is replaceable via monkeypatch. The function should compute the base64-encoded length and raise RuntimeError if it doesn't match the constant.

For rate-limit cancellation: use `asyncio.create_task` to spawn a request that pauses at a known point (e.g. via `monkeypatch` on bcrypt.checkpw to introduce a sleep), then call `task.cancel()`. After cancellation, assert the rate-limit state structure (likely `_attempts` dict) does not have the cancelled slot.

For X-Forwarded-For: PR-068 (or pre-existing config) already exposes `trusted_proxy_ips`. Set it to `127.0.0.1` in fixtures, then send requests with various peer/forwarded combinations.
