## Files to create

`tests/e2e/__init__.py` (empty file, marker for pytest discovery).

`tests/e2e/conftest.py`:
- `live_server` fixture (session-scoped). Uses `uvicorn.Server(Config(...))` with `host="127.0.0.1"` and `port=0` (OS-assigned free port). Starts the server in an asyncio task; waits for the port to be listening (poll); yields `f"http://127.0.0.1:{port}"`. On teardown, signals shutdown via `server.should_exit = True` and awaits the task.
- `fresh_db` fixture (function-scoped). Creates `sqlite:///{tmp_path}/megaraid.db`; runs alembic upgrade head against it; yields the URL.
- `test_admin_creds` fixture (function-scoped). Generates bcrypt hash for password `"e2e-test-pass-1234"` using `bcrypt.hashpw(..., gensalt(rounds=4))` (low rounds OK for tests). Creates tmp env file. Writes minimal valid env (ADMIN_USERNAME, ADMIN_PASSWORD_HASH, DATABASE_URL pointing at fresh_db, ALERT_FROM/TO with @example.com placeholder, ALERT_SMTP_HOST=smtp.invalid, ALERT_SMTP_USER=test, ALERT_SMTP_PASSWORD=test, STORCLI_PATH pointing at a stub script in tmp_path with mode 0755). Yields dict.
- The `live_server` fixture must read settings from `test_admin_creds.env_file` via `monkeypatch.setenv("ENV_FILE", ...)` or by `os.environ` priming before app import.

@pytest.mark.asyncio

## Implementation notes

The `live_server` fixture is the trickiest part of e2e setup. Recommended pattern:

```python
import asyncio
import socket
import contextlib
import pytest_asyncio
from uvicorn import Config, Server

def _free_port() -> int:
    with contextlib.closing(socket.socket()) as s:
        s.bind(("127.0.0.1", 0))
        return s.getsockname()[1]

@pytest_asyncio.fixture(scope="session")
async def live_server(test_admin_creds):
    import os
    os.environ.update({
        "ADMIN_USERNAME": test_admin_creds["username"],
        "ADMIN_PASSWORD_HASH": test_admin_creds["password_hash"],
        "DATABASE_URL": test_admin_creds["database_url"],
        # ... other required env
    })
    from megaraid_dashboard.app import create_app
    port = _free_port()
    config = Config(app=create_app(), host="127.0.0.1", port=port, log_level="warning")
    server = Server(config)
    task = asyncio.create_task(server.serve())
    # Wait for the server to be listening
    for _ in range(50):
        await asyncio.sleep(0.1)
        if server.started:
            break
    yield f"http://127.0.0.1:{port}"
    server.should_exit = True
    await task
```

The fixture ordering: `test_admin_creds` -> `fresh_db` (which `test_admin_creds` depends on internally for DATABASE_URL) -> `live_server`. The smoke test only needs `live_server` and `page` (which pytest-playwright provides automatically).

Stub storcli script for STORCLI_PATH: a 5-line bash script that exits 0 with empty JSON `{"Controllers": [{"Response Data": {}}]}` on any args. The app won't call it during smoke test (healthz doesn't hit storcli), but the validator from PR-070 requires the path to be executable.

Document in the conftest that `live_server` is session-scoped (one app process for all tests in the session) but `fresh_db` is function-scoped (new DB per test). Tests that need clean state should explicitly reset via DB fixture, not by restarting the server.

## Risk

E2E infrastructure: live_server fixture interacts with asyncio + uvicorn lifecycle. Edge cases include slow startup, port collision, hung shutdown. The polling loop must have a timeout. Document the timeout.
