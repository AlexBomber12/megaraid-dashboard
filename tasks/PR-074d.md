tests/e2e/test_replace_wizard_flow.py:

```python
import pytest

@pytest.mark.asyncio
async def test_replace_wizard_serial_mismatch_rejected(
    authenticated_page, live_server, snapshot_with_drives
):
    # Capture CSRF
    await authenticated_page.goto(f"{live_server}/")
    cookies = await authenticated_page.context.cookies(f"{live_server}/")
    token = next(c["value"] for c in cookies if c["name"] == "__Host-csrf")

    # Submit replace/offline with a WRONG serial number
    # The snapshot fixture inserts drive in 252:0 with serial starting "WCA275678000"
    response = await authenticated_page.request.post(
        f"{live_server}/drives/252:0/replace/offline",
        data={
            "expected_serial": "WRONG-SERIAL-1234",
            "confirm": "OFFLINE 252:0",
        },
        headers={"X-CSRF-Token": token},
    )
    assert response.status == 409, f"expected 409, got {response.status}"
    body = await response.text()
    # The error message should be visible in the response body
    assert "serial" in body.lower() or "mismatch" in body.lower()
```

async def test_static_css_served_without_auth(live_server, page):

.github/workflows/ci.yml (add a new job at the end of the existing workflow):

```yaml
  e2e:
    name: E2E (Playwright)
    runs-on: ubuntu-latest
    needs: ci
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: "3.12"
          cache: pip
      - name: Cache Playwright browsers
        id: playwright-cache
        uses: actions/cache@v4
        with:
          path: ~/.cache/ms-playwright
          key: playwright-chromium-${{ runner.os }}-${{ hashFiles('pyproject.toml') }}
      - name: Install project and dev dependencies
        run: pip install -e ".[dev]"
      - name: Install Playwright browsers
        if: steps.playwright-cache.outputs.cache-hit != 'true'
        run: playwright install --with-deps chromium
      - name: Install Playwright system deps (always)
        run: playwright install-deps chromium
      - name: Run e2e tests
        run: pytest tests/e2e/ --browser chromium -v
```

The existing ci job structure is preserved; only the new e2e job is appended.

## Implementation notes

CI job ordering: the e2e job has needs: ci so it runs only after the main ci job passes. This prevents wasting Playwright runner time on PRs that already fail unit tests.

Playwright browser cache: the cache key includes pyproject.toml hash so any deps change invalidates the cache. This is conservative; for stricter caching, use a hash of just the playwright version, but pyproject hash is simpler and still correct.

playwright install-deps is run unconditionally (separately from the conditional install command) because system-package deps don't persist across runner instances even when the browser binary cache hits.

For the replace wizard test: the exact form fields depend on the routes implementation. The example uses expected_serial and confirm but the real endpoint may use different field names. Verify by inspecting templates/drives_replace.html or the route's request model before writing the test. Adjust field names to match.

For the events page test: the snapshot_with_drives fixture (added in PR-074c) creates a snapshot but no events. To make the test more meaningful, either:
- Insert one event manually in this test's setup (acceptable; pattern follows snapshot_with_drives).
- Just verify the page renders (empty-state). Simpler and still validates the route is reachable.

This task picks the simpler option to minimize state-setup complexity.

## Risk

CI runtime: e2e tests are slow. Initial estimate is 60-120 seconds for the full suite. Monitor over the first few PRs after merge. If runtime exceeds 3 minutes, split fast smoke tests (auth, healthz, static) from slow stateful tests (maintenance, locate, replace) into separate jobs that run in parallel.
