## Problem

After PR-082-086 land, the legacy overview page, the legacy controller-related view models, and the v2-namespaced CSS classes are no longer in use. The legacy code increases test surface, increases coverage requirements, and confuses future contributors.

Remove the dead code in a single focused PR.

## Scope

In scope:

1. Remove legacy templates that are no longer referenced:
   - `templates/pages/overview.html` (replaced by main.html in PR-082).
   - `templates/partials/overview_data.html` (was HTMX partial for legacy overview).
   - `templates/partials/status_tile.html` (legacy strip tile component).
   - `templates/partials/activity_timeline.html` (replaced by activity_timeline_v2 in PR-082).
   - Verify each is not referenced by `grep -r '<file>' src/ tests/`.

2. Remove legacy view models from `services/overview.py`:
   - `StripTileViewModel`
   - `OverviewStripSection`
   - `OverviewViewModel` (the legacy combined model; new code uses MainPageViewModel from PR-075).
   - All `_load_*_tile` helper functions feeding the strip.
   - Keep `RecentActivityItem`, `derive_controller_health`, and other still-referenced classes/helpers.

3. Remove the legacy route partial endpoint if no longer used:
   - `GET /partials/overview` (was HTMX polling endpoint for legacy overview).
   - Verify no callers via grep.

4. Rename v2-suffixed templates/classes to drop the suffix:
   - `templates/pages/drive_detail_v2.html` -> `drive_detail.html` (overwrite the old file).
   - `templates/partials/activity_timeline_v2.html` -> `activity_timeline.html`.
   - CSS class `.chart-canvas-v2` -> `.chart-canvas` (the old one is removed because it had aspect-ratio bug).
   - CSS class `.site-header-v2` -> `.site-header`.
   - Update all template references accordingly.

5. Remove legacy `.chart-canvas` CSS rules that had `aspect-ratio: 16/6` (the "growing chart" bug). The new fixed-height rule is the only version going forward.

6. Update `static/css/app.css` to consolidate sections:
   - Move all redesign-specific styles to a coherent location.
   - Remove dead CSS for `.site-header` (the legacy version), `.overview-strip`, `.status-tile`, etc.

7. Delete corresponding tests that no longer apply:
   - `tests/test_services/test_overview_strip.py` (if exists).
   - `tests/test_web/test_overview_strip*.py` (if exists).
   - Any test for partials being deleted.

8. Update documentation:
   - `docs/ARCHITECTURE.md`: remove references to legacy view models.
   - `README.md`: remove references to legacy layout if any.

Out of scope:
- New features.
- Adding tests (the deleted tests are removed because their target code is removed).
- DB schema changes.

## Implementation notes

This PR is dangerous: deleting code can break things if cross-references are missed. Process:

1. Run grep for each deleted/renamed file's name + each deleted class name + each renamed CSS class. List all references found in this PR description.
2. Update or delete each reference.
3. Run full test suite. Anything broken = either a real bug or a missed reference.
4. Verify visually: open every page (/, /controller, /drives/252:0, /events, /audit) - all render OK.

Coverage gate is 100%. Deleted code = deleted coverage. The gate continues to apply to remaining code.

If any test fails because of the deletion, either fix the test (if the deletion was incidental) or restore the code (if the test reveals an unintended consumer).

## Risk

Deletion can break things. To minimize:
- One commit per logical change (deletion, rename, CSS consolidation, test cleanup).
- Run full test suite + Playwright e2e between each commit.
- Deploy to dev environment and smoke test before merging.

## Success criteria

1. ruff/mypy/format pass.
2. Full test suite passes (including Playwright e2e from PR-087).
3. 100% coverage maintained on remaining code.
4. Manual smoke: all 5 main pages render without error.
5. No file outside scope modified.
6. PR description lists all deleted files and all renames performed.
