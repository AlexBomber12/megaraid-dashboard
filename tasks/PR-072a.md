## Implementation notes

For `app.py:_retry_collector_scheduler_start` retry path:
```python
import asyncio
import fcntl
import os

@pytest.mark.asyncio
async def test_collector_retry_success_after_lock_held_then_released(tmp_path, monkeypatch):
    lock_path = tmp_path / "collector.lock"
    held_fd = os.open(str(lock_path), os.O_CREAT | os.O_RDWR, 0o600)
    fcntl.flock(held_fd, fcntl.LOCK_EX | fcntl.LOCK_NB)
    # Configure short retry interval
    # Start the app via TestClient
    # After short delay, release held_fd
    # Assert retry log line "collector_lock_acquired" appears
    # ...
    os.close(held_fd)
```

For `__main__.py`: `runpy.run_module` re-executes the file with `__name__ == "__main__"`, triggering `main()`. With `uvicorn.run` patched, both the function definition and the entry-point conditional get covered.

For DB chmod tests: use `tmp_path` for a fake DB file, set mode 0644, run app startup, verify chmod to 0600. Use `caplog` to capture the structlog/logger output to assert the right log line.

For `iso_utc` ValueError: it should reject `datetime.now()` (naive). Tests pass a naive datetime and assert exception type.
