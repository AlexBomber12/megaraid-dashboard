# PR-085: Backplane position diagram reusable component

Branch: pr-085-backplane-diagram-component
- Type: feature
- Complexity: low
- Depends on: PR-084
- Priority: 3
- Coder: any

## Problem

The backplane position diagram (8 mini slots showing where the current drive sits) was implemented inside PR-084 as part of drive detail page. The same diagram is useful on the main page (showing physical slot layout next to the drive grid) and potentially other places.

Extract into a reusable partial that takes a list of BackplaneSlot view models and renders consistently across pages.

## Scope

In scope:

1. New partial `templates/partials/backplane_diagram.html`:
   - Takes a list of `BackplaneSlot` items (already a dataclass from PR-077).
   - Renders 8 slots in a row (Flexbox).
   - Each slot has `slot_label`, color hint from `severity`, "this" highlight when `is_this=True`, link from `detail_url`.
   - Variant prop: `compact: bool` (default False) - when True, renders smaller slots (for main page secondary use).

2. Use the partial in:
   - `templates/partials/drive_detail/physical_position.html` (replace inline implementation from PR-084).
   - (Optional) `templates/partials/drive_grid.html` on main page - if used, only when a drive is selected (e.g. via URL hash). Probably skip for main page to keep it simple.

3. CSS additions to `static/css/app.css`:
   - `.backplane-diagram` (container).
   - `.backplane-slot` (default).
   - `.backplane-slot--this` (current highlight).
   - `.backplane-slot--optimal/--warn/--crit` (severity tints).
   - `.backplane-diagram--compact` (smaller variant).

Out of scope:
- Mapping (DG:Span:Row to physical slot order) editor (separate future PR).
- 3D backplane visualization or fancy SVG (the simple Flexbox row is enough).
- Adding to main page (low priority, can be added later).

## Implementation notes

The partial uses Jinja's `with` context to receive parameters:
`{% include "partials/backplane_diagram.html" with slots=position.backplane_layout, compact=False %}`

If `compact` parameter is not passed, the partial defaults to non-compact.

Each slot is rendered as `<a class="backplane-slot backplane-slot--{{ severity_class }} {% if slot.is_this %}backplane-slot--this{% endif %}" href="{{ slot.detail_url }}">{{ slot.slot_label }}</a>`.
