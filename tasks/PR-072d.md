## Implementation notes

Replace flow is a state machine. To exercise each error path, the test must:
1. Set up snapshot DB in the correct prerequisite state (e.g. missing requires prior offline).
2. Mock the storcli runner to either succeed or raise.
3. Send the right request with valid CSRF, valid auth.
4. Assert the response code matches the missed branch documentation.

For SQLAlchemyError audit-failure paths: PR-069 unified these to return 500. Tests need to mock the session to raise SQLAlchemyError on the audit row insert; assert 500 + documented body.

For rebuild-status: the endpoint polls storcli. Mock the runner to return different states (e.g. `progress=0` for idle, `progress=50` for in-progress, `progress=100` for complete) and assert the HTML/JSON response matches.

For serial mismatch: tests should send the wrong serial in the request body and assert 409 Conflict + the inline error message in the response.
