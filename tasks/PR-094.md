## Problem

The main page diverged from the approved mockup. The operator requirement was "fits without scrolling, no empty space, no duplicated info". The current implementation violates all three:

1. A page header section ("SERVER RAID Status" + the controller model + "Updated:") was added that is NOT in the mockup. The model text duplicates the controller model already shown inside the controller card.
2. The controller state ("OPTIMAL") renders as a pill badge floating top-right. In the mockup it is large green text on the left, inline with the model.
3. The four controller metrics (RoC / CacheVault / BBU / Errors) render as three large bordered boxes with lots of empty space. In the mockup they are a compact single inline row.
4. The BBU metric is missing (only 3 metrics shown). The mockup has 4.
5. Temperatures render as "76 C". The mockup uses "76°C" (degree symbol, no space).

The cumulative effect: wasted vertical space pushes content below the fold, defeating the no-scroll requirement.

This PR restores the main page controller card and page structure to the approved mockup EXACTLY. The mockup HTML and CSS are provided verbatim below. Reproduce them faithfully; do not reinterpret the layout.

- BBU is the third metric and must always render (shows "N/A" when no BBU, which is correct for this CV controller).
