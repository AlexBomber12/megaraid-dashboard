# PR-088a: Remove legacy overview production code

Branch: pr-088a-remove-legacy-production

- Depends on: PR-087
- Priority: 3

## Problem

After PR-082 through PR-086 merged, the main page (`GET /`) renders `pages/main.html` via `load_main_page_view_model`. The legacy strip-of-tiles overview layout and its entire supporting code path are now dead: nothing references them except the legacy code cluster itself. This PR removes the legacy PRODUCTION code (Python + templates + the dead endpoint) plus the one test file that targets ONLY legacy symbols.

This PR deliberately does NOT touch the four MIXED test files that import both legacy and live symbols. Those are edited in PR-088b. Splitting prevents the tier-2 test_file_deletion guardrail from firing on a bulk delete that would also remove coverage for live code.

## Confirmed dead legacy cluster

The following form a self-contained dead cluster (verified by grep on the current codebase: nothing outside the cluster references any member):

- `GET /` previously called `_load_overview`; it now calls `_load_main_page`. The legacy path is unreferenced.
- `pages/overview.html` includes `partials/overview_data.html`, which `hx-get`s `/partials/overview`. That endpoint renders `overview_data.html`. This is a closed loop with no external entry point.
